# Meeting Card — Layer 2

### What we can state today
The current research prototype was tested on **15 unseen provisional human-reviewed cases**.

- Action: **80.0% (12/15)**; exact 95% CI **51.9%–95.7%**.
- Object: **53.3% (8/15)**; exact 95% CI **26.6%–78.7%**.
- SIF F1: **78.3%** on the same provisional holdout.

### What we should not state
Do not say “certified 80% accurate,” “100% validated,” or “production certified.”

### Recommended wording
“The model has undergone internal validation on an unseen human-reviewed holdout. Certification requires a larger, independently adjudicated test set plus an external audit of the evaluation procedure; that step has not yet been completed.”
